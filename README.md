# Braylin Jiménez · Portafolio

Portafolio profesional de Braylin A. Jiménez Reynoso, economista y data scientist en Santo Domingo, República Dominicana: machine learning, riesgo, salud y economía.

**Sitio:** <https://braylinjr.github.io/>

## Estructura

| Ruta | Contenido |
|---|---|
| `index.html` | Página completa (HTML, CSS y JavaScript en un solo archivo) |
| `assets/` | Imágenes, videos y animaciones de los proyectos |
| `.nojekyll` | Indica a GitHub Pages que publique los archivos tal cual |

## Editar

Los textos están en `index.html`. El detalle de cada proyecto (lo que se ve al abrir "Ver caso completo") está en el bloque `<script id="proj-data">` al final del archivo.

Para verlo en tu computadora:

```bash
python -m http.server 8000
```

y abre <http://localhost:8000>.
